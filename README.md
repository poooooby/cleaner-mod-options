# Cleaner Mod Options 🧹

*A tidier mod list. Hide disabled mods and mods for other games from the in-game
mod menu in Red, Blue, Yellow, Gold, Silver, Crystal, FireRed, LeafGreen, Ruby, Sapphire and Emerald.*

</div>

A UI mod for [Gen1Recomp](https://github.com/bryanthaboi/gen1recomp). Normally,
**START → OPTIONS → MODS** shows every mod you have installed, including the ones
that are switched off and the ones made for a different game. This mod lets you hide them.

## ✨ Features

### Core Mechanics

- 🙈 **Hide disabled mods:** Mods that were switched off when the game started drop out of the list.
- 🎮 **Hide mods for other games:** Mods that can't run on the game you're playing (a Gold mod
  while you play Red, a Gen 3 mod in Crystal) drop out of the list.
- 🔢 **An honest count:** The **MODS** row on the options screen counts only the mods the list
  shows, in all three generations.
- 🗂️ **No empty headings:** When every mod in a category is hidden, its heading goes too. If
  everything is hidden, the list says so instead of going blank.

### Safe by Design 🛟

- ↩️ **Undo stays in reach:** A mod you switch off during a session stays in the list until you
  restart, so a mistaken toggle can always be undone.
- 🧷 **Forced mods stay put:** A mod you've forced with **TRY HERE ANYWAY** counts as running
  here and is never hidden.
- 🔓 **Never locks you out:** This mod never hides itself, so its settings are always one menu
  away. Turn a filter off and the full list comes back.
- 🧱 **Display only:** Nothing about your mods changes. Profiles, load order, pending changes
  and the desktop launcher still see every mod you have installed.
- 🩹 **Fails gracefully:** If a future game update moves the mod menu, this mod steps aside and
  you get the usual full list.

## ⚙️ Options

Open **OPTIONS → MODS → Cleaner Mod Options**.

| Option | Choices | Default | What it does |
|---|---|---|---|
| **Hide Disabled** | On / Off | Off | Hide mods that were switched off when the game started. |
| **Hide Other Games** | On / Off | Off | Hide mods that can't run on the game you're playing. |

## 💾 Installation

1. Download the latest release from the
   [Releases](https://github.com/poooooby/cleaner-mod-options/releases) page.
2. Import it with the Gen1Recomp Mod Manager, or drop it in your mods folder.
3. Enable it, then turn on the filters you want in its options.

## 📌 Good to Know

- Both filters start **Off**, so the list looks exactly as before until you turn one on.
- A mod hidden by **Hide Disabled** can be switched back on from the desktop launcher's MODS
  tab, or by turning the filter off.
- The desktop launcher's mod list is never filtered.
