# Changelog

## 1.0.0

- First release.
- HIDE DISABLED: hides mods that were disabled at boot from START > OPTIONS >
  MODS (staged toggles stay visible until restart).
- HIDE OTHER GAMES: hides mods that cannot run on the game being played
  (TRY HERE ANYWAY mods stay visible).
- Both settings default OFF, in OPTIONS > MODS > Cleaner Mod Options.
- The options screen's "N INSTALLED" count follows the filters on Gen 1, 2
  and 3.
